# Changelog

All notable changes to **Nik's Picky Adventurer (`niks-picky-adventurer`)** are documented in this file.

## [14.0.0] - 2026-11-13
### Changed
- **New name**: The module is now **Nik's Picky Adventurer**, based on kaelad's Picky Adventurer. It installs as a new module, so disable the old Picky Adventurer before enabling this one.
- **Foundry V14**: Verified for Foundry V14. Foundry V13 keeps working.

### Added
- **German translation**.

### Fixed
- **D&D 5e import options**: Extra import steps you ticked in a D&D 5e adventure's import window were skipped once you picked your documents. They run again now.
