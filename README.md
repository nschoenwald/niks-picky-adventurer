Import only the parts of an adventure you need. Deleted a scene, changed the wrong actor or edited a journal by mistake? Get back just that document, without re-importing the whole adventure and overwriting everything you customized. Works with **any game system** in **Foundry VTT v13 and v14**, including **D&D 5e 6.x**.

![Screenshot](screenshot1.webp)

---

## ✨ Features

- **Where to find it**: Start the import of an adventure as usual. Instead of importing right away, a **Picker** window opens.
- **Create and Update tabs**: **Create** lists documents that aren't in your world yet. **Update** lists documents that already exist and would be overwritten.
- **Grouped like your sidebar**: Documents are grouped by type (scenes, actors, journals…) and by folder, in the adventure's folder order.
- **Add All / Remove All**: Pick or clear every document of a type with one click.
- **Import**: Only the documents you picked are created or updated. Everything else in your world stays as it is.
- **Adventure options are kept**: The options you chose in the adventure's import window still apply, including the extra import steps some D&D 5e adventures offer.

## 📦 Installation

In Foundry, go to **Add-on Modules → Install Module** and paste this manifest URL:
```
https://github.com/nschoenwald/niks-picky-adventurer/releases/latest/download/module.json
```

Requires **Foundry VTT v13 or v14**. Works with any game system.
